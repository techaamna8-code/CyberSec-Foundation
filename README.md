# TryHackMe: Offensive Security Intro (Walkthrough & Notes)

A brief documentation of concepts covered in the **Offensive Security Intro** room on TryHackMe.

---

## 📌 Room Overview
- **Platform:** TryHackMe
- **Category:** Introduction to Cyber Security / Pre-Security
- **Objective:** Understand how ethical hackers think, identify vulnerabilities in web apps, and simulate basic attacks in a safe environment.

---

## 🔍 Key Concepts Learned

### 1. The Hacker Mindset
- Defensive vs. Offensive security approach.
- Looking at a system not just as a user, but asking: *"What happens if I try to access pages or functions I'm not supposed to see?"*

### 2. Web Reconnaissance & Directory Enumeration
- Finding unlinked, hidden, or administrative pages (e.g., `/admin`, `/login`, `/portal`).
- Understanding how brute-forcing directories reveals sensitive endpoints.

### 3. Exploitation & Access Control
- Interacting with unprotected admin panels.
- Understanding the risk of default credentials and insecure backend configurations.

---

## 🛠️ Practical Takeaways
- Always enforce proper authentication and authorization checks on all endpoints.
- Avoid exposing default administrative paths directly on the internet.
- Perform continuous testing and code audits before deploying applications.
